# mrrjanai.github.io

Source for my portfolio site: **https://mrrjanai.github.io**

Plain HTML, CSS and a little JavaScript. No build step. GitHub Pages serves it straight from `main`.

## Adding a project

1. Put screenshots in `assets/<slug>/` (about 1650×1080 works well).
2. Add an entry to `projects.js`. The first entry in the list shows at the top.
3. Commit and push. The site updates within a minute or two.

## Preview locally

Open `index.html` in a browser, or run `npx serve .` and visit the printed URL.
